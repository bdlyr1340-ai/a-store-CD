# My Bot Store Clean v2

نسخة نظيفة وجديدة من البوت، مبنية على فكرتك الأساسية، بدون الأكواد الزائدة الموجودة بالمشروع القديم.

## المحذوف جذرياً

- مساعد الذكاء الاصطناعي وOpenAI.
- إدارة بوتات إضافية وBot API داخل المتجر.
- الخانات الرقمية الديناميكية.
- الإحالات ومخزون ChatGPT الخاص بالإحالات.
- البوتات الخدمية والمواقع الخارجية الغريبة.
- البروكسي الخارجي الذي كان يستلم مفاتيح Binance.
- ملفات النسخ الاحتياطية والترقيعات القديمة.
- الاشتراك الإجباري بالقنوات والميزات غير الضرورية.

## الموجود

- المنتجات تظهر مباشرة لكل مستخدمي المتجر.
- عربي وإنجليزي.
- CAPTCHA حسابي بسيط.
- لوحة إدارة داخل البوت بالأمر `/admin`.
- بطاقة تعديل منتج تعرض كل الحقول بوضوح:
  الاسم العربي والإنجليزي، السعر، القسم، النوع، الوصف، الضمان، الصورة، عدد المشتركين، المخزون والنشر.
- حساب شخصي ينباع مرة واحدة.
- حساب مشترك ينباع تلقائياً 5 مرات افتراضياً، أو أي عدد تحدده.
- كود، حساب ينتظر كود، إيميل وباسورد و2FA.
- رفع المخزون كنص أو TXT/CSV.
- محفظة وشراء من الرصيد.
- شحن المحفظة تلقائياً عبر Binance Pay، أو يدوياً عبر SuperQi.
- Binance Pay Merchant مباشر بدون أي سيرفر وسيط.
- التحقق التلقائي بثلاث طرق:
  Webhook، زر «تحقق من الدفع»، وفحص احتياطي كل 90 ثانية.
- SuperQi يدوي:
  يحسب الدولار بالدينار، يعرض الرقم `917392710336`، يستلم صورة الإيصال، والإدارة توافق أو ترفض.
- PostgreSQL ويحافظ على البيانات عند تحديث Railway.
- تشفير AES-256-GCM للحسابات والباسوردات و2FA، مع ترحيل المخزون القديم من النص المكشوف تلقائياً.
- يحاول استخدام جداول البوت القديم نفسها للمنتجات والمخزون والمستخدمين، ويضيف الأعمدة الجديدة بدون حذف البيانات القديمة.

## تنبيه Binance

التأكيد التلقائي يحتاج مفاتيح **Binance Pay Merchant**:

```env
BINANCE_PAY_API_KEY=
BINANCE_PAY_SECRET_KEY=
```

مفاتيح Binance Spot العادية (`BINANCE_API_KEY`) ليست بديلاً عن مفاتيح Merchant، ولا تكفي لإنشاء طلب Binance Pay وشحنه تلقائياً.

Webhook الذي تضيفه في لوحة Binance Pay:

```text
https://YOUR-DOMAIN.up.railway.app/webhooks/binance-pay
```

## النشر

الأفضل إنشاء مستودع GitHub جديد لهذه النسخة. لا ترفع ملف `.env`.

1. ارفع ملفات المشروع إلى GitHub.
2. اربطه بخدمة Railway.
3. أضف PostgreSQL داخل المشروع.
4. انسخ متغيرات `.env.example` إلى Variables.
5. اربط `DATABASE_URL` عن طريق Reference Variable إلى Postgres.
6. اجعل Target Port هو `3000`.
7. بعد Active أرسل `/start` ثم `/admin`.

## المخزون

أرسل كل حساب بسطر:

```text
email@example.com|password|2FA_SECRET
email2@example.com|password2
ONLY-CODE-HERE
```

عند كون المنتج «مشترك» وعدد المشتركين 5، نفس السطر يباع خمس مرات، ويسجل كل مشترٍ ورقم استخدامه، ثم ينتقل تلقائياً للسطر التالي.

## مفتاح تشفير المخزون

ولّد المفتاح مرة واحدة:

```bash
openssl rand -hex 32
```

ضع الناتج في `INVENTORY_ENCRYPTION_KEY`. لا تغيّره بعد إضافة المخزون.
