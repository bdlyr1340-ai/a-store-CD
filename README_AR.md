# CD Store v4 — متجر تليجرام رقمي

هذه النسخة تحديث مباشر لمشروع CD Store v3 وتستخدم نفس PostgreSQL ونفس متغيرات Railway.

## التحديث من v3

استبدل الملفات التالية داخل GitHub:

```text
package.json
src/bot.js
src/db.js
src/utils.js
src/services/orders.js
```

وأضف الملف الجديد:

```text
src/services/referrals.js
```

بعد Commit انتظر Railway حتى يصير Active. أول تشغيل ينشئ الجداول والأعمدة الجديدة وينظف المخزون غير الصحيح والمكرر.

## لا تغيّر هذا المتغير

```env
INVENTORY_ENCRYPTION_KEY=نفس_القيمة_القديمة
```

تغييره يمنع قراءة الحسابات المشفرة القديمة.

## صيغ المخزون

### حساب شخصي

```text
email@example.com|password
email@example.com|password|2FA_SECRET
```

### حساب مشترك

```text
email@example.com|password
```

المشترك يرفض 2FA تلقائياً. عدد مرات البيع يُحدد من حقل الإدارة السري، مثلاً 5.

### كود

```text
CODE-ONE
CODE-TWO
```

### حساب ينتظر كود

```text
email@example.com
email@example.com|password
```

## إلغاء أي عملية

اكتب:

```text
إغلاق
```

أو:

```text
/cancel
```

المنتج الجديد لا ينضاف إلى قاعدة البيانات إلا بعد إكمال جميع الخطوات.

## الدعم داخل البوت

الزبون يضغط «الدعم» ويرسل نصاً أو صورة أو ملفاً. تصل الرسالة إلى الإدارة داخل البوت مع زري:

```text
رد
إغلاق
```

ولا يُحوَّل المستخدم إلى حسابك الخاص.

## القناة الإجبارية

من:

```text
/admin
→ الإعدادات
→ القناة الإجبارية
```

أرسل معرف قناة عامة مثل:

```text
@mychannel
```

لازم تضيف البوت مشرفاً في القناة حتى يقدر يتحقق من الأعضاء. لإيقافها اضغط «إيقاف القناة» أو أرسل `-`.

## الهدايا والمشاركة

من:

```text
/admin
→ الهدايا والإحالة
```

تقدر تتحكم بـ:

- تشغيل أو إخفاء نظام الإحالة.
- مكافأة كل مستخدم جديد، الافتراضي 0.05$.
- عدد الإحالات المطلوبة، الافتراضي 10.
- اختيار أي منتج موجود كهدية.
- تشغيل أو إخفاء الهدية.

عند دخول شخص جديد من رابط الإحالة، لازم يكمل CAPTCHA وينضم للقناة الإجبارية إن كانت مفعلة. بعدها تُضاف المكافأة إلى محفظة صاحب الرابط. وعند الوصول للعدد المطلوب يحاول البوت تسليم منتج الهدية تلقائياً من المخزون.

## فتح وإغلاق المتجر

```text
/admin
→ فتح/إغلاق المتجر
```

عند الإغلاق تتوقف المنتجات والشراء والشحن، لكن الدعم والطلبات السابقة يبقون متاحين.

## إدارة المستخدمين

```text
/admin
→ إدارة مستخدم
```

أرسل Telegram ID حتى تشوف معلوماته وتقدر تشحن رصيده أو تحظره أو تفك الحظر.

## الدفع

- Binance ID: التحقق برقم عملية Binance مثل الإصدار السابق.
- SuperQi: تحويل يدوي وإرسال صورة، ثم موافقة الإدارة.
