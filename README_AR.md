# CD Store v3 — Binance ID Verification

هذه النسخة مبنية على البوت النظيف السابق، لكن نظام Binance تغيّر بالكامل من Merchant Order إلى نفس الطريقة القديمة:

1. البوت يعرض Binance ID والمبلغ.
2. يولّد رمز ملاحظة خاص بالطلب.
3. الزبون يحوّل ويكتب الرمز بالملاحظة.
4. يضغط «تحقق برقم الطلب» ويرسل Binance Order ID.
5. البوت يقرأ سجل Binance Pay من الحساب مباشرة.
6. يطابق رقم العملية والمبلغ والعملة ويمنع استخدام العملية مرتين.
7. بعدها يشحن المحفظة أو يسلّم المنتج تلقائياً.

لا يوجد Webhook ولا سيرفر وسيط ولا إرسال مفاتيح إلى موقع خارجي.

## التعديلات الجديدة

- إصلاح حفظ وظهور الوصف العربي والإنجليزي.
- إضافة حقل «المالك/المصدر» لكل منتج، يظهر داخل لوحة الإدارة فقط.
- معلومات الحساب المشترك وعدد مرات البيع لا تظهر للزبائن.
- الحساب المشترك يستمر بالبيع حسب العدد السري المحدد، ثم ينتقل للحساب التالي.
- لوحة الإدارة وأمر `/admin` يظهران ضمن أوامر تليجرام لحساب الإدارة فقط.
- إدارة مستخدم بالآيدي:
  - عرض الرصيد والحالة والطلبات.
  - شحن الرصيد يدوياً.
  - حظر المستخدم.
  - فك الحظر.
- إصلاح تشغيل Polling ومسح Webhook تليجرام القديم قبل التشغيل.
- إصلاح أخطاء SuperQi وتخزين الوصف JSONB.
- تشفير المخزون كما كان.

## متغيرات Binance في Railway

استخدم مفتاح API عادي من Binance بصلاحية القراءة فقط:

```env
BINANCE_API_KEY=...
BINANCE_API_SECRET=...
BINANCE_PAY_ID=PUT_YOUR_BINANCE_PAY_ID_HERE
BINANCE_API_BASE_URL=https://api.binance.com
```

لا تفعل:

- Spot Trading
- Margin Trading
- Withdrawals

إذا قيدت المفتاح على IP، لازم تضيف Outbound IP مال Railway. للتجربة الأولى يمكن إنشاء مفتاح قراءة فقط بدون IP restriction، وبعد التأكد استخدم IP ثابت.

المشروع يقبل مؤقتاً أسماء المتغيرات القديمة `BINANCE_PAY_API_KEY` و`BINANCE_PAY_SECRET_KEY` حتى لا يتوقف النشر، لكن الأفضل تغييرها للأسماء أعلاه.

```text
src/config.js
src/db.js
src/index.js
src/bot.js
src/utils.js
src/payments/binancePay.js
.env.example
README_AR.md
package.json
```

بعد الرفع:

1. افتح Railway Variables.
2. أضف مفاتيح Binance الجديدة وPay ID.
3. Deploy Changes أو Redeploy.
4. داخل Deploy Logs يجب أن يظهر:

```text
Database ready
Telegram webhook cleared
Telegram bot polling started
Health server listening on 0.0.0.0:3000
```

## المخزون المشترك

إذا نوع المنتج «مشترك» والعدد السري 5، كل سطر مخزون يباع خمس مرات ثم ينتقل للسطر التالي. الزبون لا يرى عبارة «يباع خمس مرات» ولا رقم خانته. الإدارة وحدها ترى تفاصيل الاستخدام.
