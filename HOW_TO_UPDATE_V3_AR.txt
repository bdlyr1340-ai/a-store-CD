الطريقة الأسرع:

1. فك ضغط ملف CD-Store-v3-UPDATE-ONLY.zip.
2. ارفع محتوياته إلى نفس مستودع GitHub ووافق على استبدال الملفات بنفس المسارات.
3. داخل Railway > Variables أضف أو حدّث:
   BINANCE_API_KEY
   BINANCE_API_SECRET
   BINANCE_PAY_ID
4. لا تفعل التداول أو السحب في مفتاح Binance؛ اترك القراءة فقط.
5. انتظر Railway حتى يصير Active.
6. جرّب المحفظة > شحن Binance ID > مبلغ 1$.
7. بعد التحويل، الصق Binance Order ID داخل البوت.

لوحة المالك:
/admin

منها تقدر:
- تضيف وتعدل المنتجات.
- تضيف المالك/المصدر سرياً.
- تحدد عدد مرات بيع الحساب المشترك.
- تدير المستخدم بالآيدي.
- تشحن رصيده وتحظره أو تفك الحظر.
